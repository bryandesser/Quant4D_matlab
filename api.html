quant4d package

Pure functions used by the app (file readers, annular/CoM/DPC detectors, iCoM/dCoM, scan-rotation search). They need no GUI, so they can be called from scripts and are covered by the unit tests in tests/unit. Call them with the package prefix, e.g. quant4d.readRaw(...).

quant4d.dpcCoM(data, segMasks, annularMask, centroids, nFrames, scanRotationDeg)

DPCCOM Centre-of-mass estimate from a segmented (DPC) detector.

Each segment’s signal is divided by the total in the annulus and weighted by its centroid. With many segments and rungs this converges to quant4d.centerOfMass() with the same annulus.

Usage:

[comx, comy] = quant4d.dpcCoM(data, segMasks, annularMask, centroids, nFrames, scanDeg)
Parameters:

  • data (array) – prod(nPixels) x prod(nFrames), as app.data (CPU or gpuArray)

  • segMasks (logical) – from quant4d.segmentMasks()

  • annularMask (logical) – [kx ky] full annulus, for normalisation

  • centroids (double) – from quant4d.segmentCentroids(), same rotation as the masks

  • nFrames ([int int]) – scan size [rx ry]

  • scanRotationDeg (double) – scan rotation, applied once to the result

Returns:

  • comx (double | single) – [rx ry] x component in detector pixels

  • comy (double | single) – [rx ry] y component; multiply by mrad/px for mrad

quant4d.screenInfo()

SCREENINFO Screen size, usable work area and window-decoration sizes, without needing Java.

Replaces the Java (java.awt / javax.swing) calls in the app’s get_screen_info, which fail in MATLAB releases that ship without a Java runtime (R2026b by default). Uses Java when it is available, .NET on Windows otherwise, and fixed defaults as a last resort. All sizes are in MATLAB pixels.

Usage:

quant4d.periodsToBand(periods)

PERIODSTOBAND iCoM/dCoM band-pass from feature sizes in scan pixels.

Keeps features whose repeat length is between minPx and maxPx scan pixels: maxPx sets the low-frequency cut (slow background, drift) and minPx the high-frequency cut (noise). minPx <= 1 and maxPx >= the larger scan size (or Inf) mean no filtering. The order of the two values does not matter.

quant4d.minimizeCurl(comx, comy, scanDeg, flipY)

MINIMIZECURL Scan rotation and y flip that make a CoM field curl-free.

The CoM of a thin specimen is a gradient field, so the right scan rotation and flip make its curl vanish. The rotation is found to 0.1 degrees; the 180-degree ambiguity, which the curl cannot see, is resolved by preferring positive total divergence, as the app did. Replaces the app’s minimize_curl: NaN frames no longer break it and the Mapping Toolbox is no longer needed.

Usage:

  • scanDeg (double) – current scan rotation in degrees

  • flipY (bool) – current y flip

Returns:

  • scanDeg (double) – scan rotation to use, -180 to 180 degrees

  • flipY (bool) – y flip to use

  • curlScore (double) – remaining mean absolute curl

quant4d.segmentCentroids(nseg, nrung, r_in, r_out, rotation_deg)

SEGMENTCENTROIDS Nominal centre of mass of every DPC segment, in detector pixels.

Rows are ordered like quant4d.segmentMasks(). The centroid of an annular sector of half-angle a (radians) between radii r1 and r2 is 2 sin(a) / (3 a) * (r2^3 - r1^3) / (r2^2 - r1^2).   • rOut (double) – outer radius in pixels

  • rotationDeg (double) – detector rotation in degrees

Returns:

v (double) – nseg*nrung x 2 centroid vectors [x y]

quant4d.radialBins(nPixels, center, stepPx, maxRadius)

RADIALBINS Ring masks of equal width around the beam centre, for fast BF/ADF imaging.

Pixel p is in ring k when edges(k) <= r(p) < edges(k+1), with r measured from the centre. Multiplying the rings by the data once gives a stack of ring images; any annular image is then a sum of rings, chosen with quant4d.binRange() so it equals the drawn mask exactly.

Parameters:

  • nPixels ([int int]) – detector size [kx ky]

  • center ([double double]) – beam centre [x y] in pixels, 1-based

  • stepPx (double) – ring width in pixels

  • maxRadius (double) – largest radius to cover

Returns:

  • bins (logical) – one row per ring, one column per detector pixel

  • edges (double) – ring edges 0, stepPx, 2*stepPx, … past maxRadius

quant4d.readRaw(path, dims, opts)

READRAW Read a raw binary 4D-STEM file into a (kx, ky, rx, ry) array.

Detector crop, binning and scan sampling are applied while reading. Integer data is returned as single (double for 64-bit types), so it can be used with mtimes. Replaces the “Physical Memory” branch of the app’s read_file, which used a hard-coded 4-byte stride, ignored the byte order, kept integer classes and summed (rather than sampled) probe positions.

Usage:

data = quant4d.readRaw(path, [kx ky rx ry])
data = quant4d.readRaw(path, [kx ky rx ry], Order="rk", DataType="uint16", ByteOrder="b")
[data, cancelled] = quant4d.readRaw(..., Progress=@(done, total) keepGoing)
Parameters:

  • path (str) – file to read

  • dims ([int int int int]) – detector and scan size [kx ky rx ry] of the whole file, whatever its layout

  • Order (str) – file axes, fastest first: “kr” (kx ky rx ry, frames contiguous, default), “kr_inv” (ky kx ry rx), “rk” (rx ry kx ky, probe positions contiguous) or “rk_inv” (ry rx ky kx)

  • DataType (str) – MATLAB class of the stored values, e.g. “single”, “uint16”

  • ByteOrder (str) – “l” (little-endian, default) or “b” (big-endian)

  • Offset (int) – bytes before the first block

  • Header (int) – bytes before each block of the two fastest file axes

  • Footer (int) – bytes after each such block (EMPAD: 1024)

  • PixelStart ([int int]) – first detector pixel [kx ky] to read, 1-based

  • NumPixels ([int int]) – output pixels after binning; NaN = as many as fit

  • Binning (int) – detector binning factor; sums Binning x Binning pixels

  • FrameStart ([int int]) – first probe position [rx ry], 1-based

  • NumFrames ([int int]) – output probe positions; NaN = as many as fit

  • Sampling (int) – keep every Sampling-th probe position along rx and ry

  • Progress (function_handle) – called as Progress(done, total); return false to cancel

Returns:

  • data (single | double) – (kx, ky, rx, ry) array, or [] if cancelled

  • cancelled (bool) – true if Progress returned false

Returns:

  • icom (double) – integrated CoM [rx ry], zero mean

  • dcom (double) – divergence of the CoM field [rx ry]
